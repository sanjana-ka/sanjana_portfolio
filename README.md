# Sana portfolio
Static site (no build step). Open index.html or deploy to Vercel as-is.

Add your work: drop images into /images using the filenames listed at the top of app.js
(e.g. pipetech-1.png, shelterings-1.png, csi-study-circle.png). Until a file exists, the
dashed pink placeholder from Figma is shown.

Navigation: click prev/next/contents, arrow keys, or swipe. Deep links: /#/5 opens slide 5.
